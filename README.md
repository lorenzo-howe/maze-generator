# Maze Generator

A random grid maze generator using an original multi-seed growth algorithm, plus statistical analysis of the maze's structural metrics across many runs.

## How the algorithm works

A maze is, in practice, a tree spanning the whole grid: every cell is connected to the others through exactly one possible path, with no cycles.

Instead of growing the maze from a single starting point, the algorithm places several random **seeds** on the grid and grows them all together, a bit at a time:

1. Each seed is the start of its own "lineage". At each step, a frontier cell (a cell that can still expand) is chosen at random, and its neighboring cells on the grid are examined.
2. A neighboring cell is a valid growth candidate if:
   - it hasn't been claimed by any lineage yet, or
   - it's already claimed, but by a lineage different from the current one that has never merged with it.
3. If the neighboring cell belongs to the **same** lineage, it's discarded: connecting it would create a cycle, since a path already exists between the two cells through their shared seed.
4. Among the valid neighboring cells, a number of "branches" to add is chosen: most of the time just 1 (the path simply extends), but sometimes 2 or 3, to give the maze a more organic, natural look instead of overly regular corridors.
5. If the chosen cell was free, it joins the current lineage and becomes a new growth point. If it belonged to a different lineage, the two lineages are merged into one: from that point on, no cell of one can ever connect to a cell of the other (otherwise a cycle would form).
6. A frontier cell with no more valid neighbors is removed from the frontier. The process continues until there are no more active frontier cells: at that point the maze is complete and every cell in the grid is reachable from any other through exactly one path.

The result is a "perfect" maze (no cycles, no isolated cells), generated by growing and merging multiple regions at once instead of from a single point, with weighted branching that makes it look more organic.

## Metrics

From the generated maze, the following metrics are computed via a breadth-first traversal (BFS) starting from cell `(0,0)`:

- **dead_ends** — number of dead ends
- **branching_factor** — average number of branches per non-terminal cell
- **leaf_fraction** — fraction of cells that are dead ends
- **solution_length** — length of the path from cell `(0,0)` to the opposite cell `(height-1, width-1)`
- **longest_path** — maximum distance reached from `(0,0)`
- **solution_tortuosity** — ratio between the solution length and the straight-line distance from start to goal

## Files
- `maze.py` — `Maze` class: maze generation and metric computation
- `main.py` — single-run usage example
- `statistical_analysis.ipynb` — statistical analysis over 1000+ runs, effect of the number of seeds on the metrics

## Usage
```python
from maze import Maze

m = Maze(15, 15, seeds=3)
m.plot_maze()
m.collect_metrics()
print(m.stats)
```
